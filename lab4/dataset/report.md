Свёрточные нейронные сети (CNN)


1. Введение

Целью данной практической работы является изучение принципов работы свёрточных нейронных сетей (Convolutional Neural Networks, CNN) и разработка приложения для классификации изображений.

Свёрточные нейронные сети являются специализированным классом нейросетевых моделей, предназначенных для обработки визуальных данных. Они широко применяются в задачах компьютерного зрения благодаря способности учитывать пространственную структуру изображений.

В рамках работы была реализована модель CNN с использованием библиотеки TensorFlow/Keras и проведено сравнение её эффективности с многослойным персептроном (MLP), реализованным в предыдущей лабораторной работе.


2. Математическая операция свёртки

Свёртка — это операция, при которой к изображению применяется небольшая матрица (ядро), перемещающаяся по входному изображению.

Формально свёртка определяется как:

S(i, j) = (X * K)(i, j) = \sum_m \sum_n X(i+m, j+n) \cdot K(m, n) (фото 1)

где:
	•	X — входное изображение,
	•	K — ядро свёртки,
	•	S — результат (карта признаков).

Свёртка позволяет выделять локальные признаки: границы, текстуры, формы.


3. Взаимодействие ядер свёртки и карт признаков

Каждое ядро свёртки выделяет определённый тип признаков.

Результатом применения ядра является карта признаков (feature map), отражающая наличие соответствующих структур в изображении.

Несколько ядер формируют набор карт признаков, которые передаются на следующий слой.


4. Операция подвыборки (subsampling)

Подвыборка (Pooling) используется для уменьшения размерности данных.

Наиболее распространённый метод:
	•	MaxPooling — выбирает максимальное значение из области.

Преимущества:
	•	уменьшение вычислительной сложности;
	•	устойчивость к смещениям;
	•	снижение переобучения.


5. Распространённые функции активации

В сверточных сетях используются следующие функции активации:
	•	ReLU — основная функция для скрытых слоёв;
	•	Softmax — для выходного слоя (многоклассовая классификация);
	•	Sigmoid — реже используется.

ReLU позволяет ускорить обучение и уменьшить проблему затухающего градиента.


6. Общий принцип работы CNN

CNN обрабатывает изображение по следующей схеме:
	1.	применение свёрток (выделение признаков);
	2.	применение функции активации;
	3.	уменьшение размерности (Pooling);
	4.	повторение этапов;
	5.	переход к полносвязным слоям;
	6.	классификация.


7. Типичная архитектура CNN и её функционирование

Типичная архитектура включает:
	•	Conv2D (свёрточные слои)
	•	MaxPooling2D
	•	Flatten
	•	Dense слои

В данной работе использовалась архитектура:
	•	Conv2D (32) → Pool
	•	Conv2D (64) → Pool
	•	Conv2D (128) → Pool
	•	Flatten
	•	Dense (128)
	•	Dense (Softmax)


8. Обучение CNN

Обучение выполняется с использованием:
	•	функции потерь: sparse_categorical_crossentropy
	•	оптимизатора: Adam
	•	метода обратного распространения ошибки

Модель обучается минимизировать ошибку классификации.


9. Преимущества свёрточных сетей

Основные преимущества CNN:
	•	учитывают пространственную структуру данных;
	•	автоматически выделяют признаки;
	•	меньше параметров по сравнению с MLP;
	•	высокая точность на изображениях.


10. Недостатки свёрточных сетей
	•	высокая вычислительная сложность;
	•	необходимость большого количества данных;
	•	сложность настройки архитектуры;
	•	длительное обучение.


11. Макропараметры CNN

К основным гиперпараметрам относятся:
	•	количество слоёв;
	•	размер ядра свёртки;
	•	количество фильтров;
	•	размер pooling;
	•	learning rate;
	•	batch size.

Правильный подбор параметров критически важен для качества модели.


12. Распараллеливание вычислений

CNN хорошо подходят для параллельных вычислений:
	•	операции свёртки могут выполняться независимо;
	•	эффективно используют GPU;
	•	ускоряют обучение на больших данных.


13. Практическое применение CNN

Свёрточные сети применяются в:
	•	распознавании изображений;
	•	обработке видео;
	•	медицинской диагностике;
	•	системах безопасности;
	•	автономных транспортных средствах.
