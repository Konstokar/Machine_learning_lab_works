Практическая работа №1

Feed-Forward нейронные сети (многослойный персептрон)

1. Введение

Целью данной практической работы является изучение принципов функционирования нейронных сетей прямого распространения (Feed-Forward Neural Networks) и разработка программного приложения для классификации визуальных образов на основе многослойного персептрона.

В рамках работы была реализована нейронная сеть, способная обучаться на наборе изображений, представленных в виде иерархии каталогов, и выполнять распознавание новых изображений. Обучение модели выполнялось с использованием библиотеки TensorFlow/Keras.

Задача относится к классу задач классификации изображений — одному из наиболее распространённых применений искусственных нейронных сетей.

2. Модель формального нейрона

Формальный нейрон представляет собой математическую модель биологического нейрона, выполняющую обработку входных сигналов посредством взвешенного суммирования с последующим применением функции активации.

Выход нейрона определяется выражением:

y = f\left(\sum_{i=1}^{n} w_i x_i + b\right)

где:
	•	x_i — входные сигналы,
	•	w_i — веса связей,
	•	b — смещение,
	•	f — функция активации.

Искусственные нейронные сети представляют собой совокупность взаимосвязанных нейронов, способных изменять параметры в процессе обучения и формировать требуемые выходные значения.

3. Функции активации

Функция активации определяет нелинейное преобразование выходного сигнала нейрона и позволяет сети моделировать сложные зависимости.

Наиболее распространённые функции:
	•	Sigmoid
	•	Hyperbolic tangent (tanh)
	•	ReLU (Rectified Linear Unit)
	•	Softmax

Функции активации позволяют сети обнаруживать нелинейные закономерности в данных, что является ключевым условием успешного обучения нейросетей.

В реализованной модели использовались:
	•	ReLU — в скрытых слоях,
	•	Softmax — в выходном слое для задачи многоклассовой классификации.

4. Модель многослойного персептрона

Многослойный персептрон (MLP) — это нейронная сеть прямого распространения, состоящая из:
	•	входного слоя,
	•	одного или нескольких скрытых слоёв,
	•	выходного слоя.

Каждый нейрон слоя полностью связан с нейронами следующего слоя. Сигналы распространяются только в одном направлении — от входа к выходу.

MLP способен аппроксимировать сложные функции и решать задачи классификации благодаря нелинейным функциям активации.

5. Задача классификации

Классификация — это задача машинного обучения, при которой объекту сопоставляется один из заранее заданных классов.

В данной работе классификация выполнялась по изображениям животных. Модель обучалась сопоставлять входное изображение соответствующей категории.

Feed-forward сети широко применяются для задач распознавания образов и классификации данных.

6. Пространство признаков и пространство состояний

Пространство признаков представляет собой множество параметров, описывающих объект.

В задаче классификации изображений признаками являются значения пикселей изображения. После преобразования изображения в числовой массив каждый пиксель становится отдельным признаком.

Пространство состояний сети определяется значениями активаций нейронов всех слоёв во время обработки входных данных.

7. Функция потерь

Функция потерь оценивает отличие между предсказанием модели и правильным ответом.

В работе использовалась функция:

Sparse Categorical Crossentropy, применяемая при многоклассовой классификации.

Цель обучения — минимизация функции потерь путём корректировки весов сети.

8. Обучение с учителем

Обучение с учителем предполагает наличие размеченной выборки, где каждому входу соответствует правильный ответ.

Алгоритм обучения:
	1.	подача входных данных;
	2.	получение предсказания;
	3.	вычисление ошибки;
	4.	корректировка весов.

Такой подход является основным методом обучения нейронных сетей для задач классификации.

9. Метод обратного распространения ошибки

Обратное распространение ошибки (Backpropagation) — алгоритм обучения нейронных сетей, основанный на вычислении градиента функции потерь относительно весов сети.

Алгоритм использует правило цепочки для определения вклада каждого веса в итоговую ошибку и последующей корректировки параметров.

Метод был предложен Румельхартом и соавторами и стал ключевым этапом развития нейронных сетей.

10. Проблемы градиентных методов: overfitting и underfitting

Overfitting — модель запоминает обучающие данные и плохо работает на новых.

Underfitting — модель недостаточно сложна и не может выявить закономерности.

Для борьбы применяются:
	•	увеличение данных,
	•	регуляризация,
	•	корректный выбор архитектуры.

11. Локальные минимумы

Функция ошибки нейронной сети имеет сложный многомерный рельеф. Во время обучения алгоритм может попасть в локальный минимум, не являющийся оптимальным решением.

Использование стохастических методов оптимизации уменьшает вероятность данной проблемы.

12. Выбор шага обучения

Шаг обучения (learning rate) определяет величину изменения весов.
	•	слишком большой шаг → обучение нестабильно;
	•	слишком маленький → медленная сходимость.

Градиентные методы оптимизации регулируют обновление параметров сети.


13. Нормализация данных

Нормализация приводит значения признаков к единому диапазону.

В работе изображения масштабировались в диапазон:

[0,1]

что ускоряет обучение и повышает устойчивость алгоритма.


14. Регуляризация

Регуляризация предотвращает переобучение модели путём ограничения сложности сети.

Примеры:
	•	Dropout,
	•	L2-регуляризация,
	•	ранняя остановка обучения.

15. Чувствительность и специфичность классификатора

Чувствительность (recall) показывает долю правильно найденных объектов класса.

Специфичность характеризует способность модели правильно отклонять объекты других классов.

Эти показатели используются для оценки качества классификаторов.


16. Практическое применение feed-forward моделей

Feed-forward нейронные сети применяются в:
	•	распознавании изображений,
	•	медицинской диагностике,
	•	анализе сигналов,
	•	финансовом прогнозировании,
	•	системах рекомендаций.

MLP остаётся одной из базовых архитектур глубокого обучения.



17. Описание реализованного приложения

В ходе работы было разработано приложение на Python с использованием TensorFlow/Keras.

Функциональные возможности:
	•	загрузка обучающего датасета из структуры каталогов;
	•	обучение многослойного персептрона;
	•	оценка точности модели;
	•	сохранение обученной модели;
	•	классификация новых изображений.

Архитектура сети:
	•	входной слой (Flatten),
	•	два полносвязных слоя (Dense + ReLU),
	•	выходной слой Softmax.

В результате выполнения практической работы были изучены принципы работы нейронных сетей прямого распространения и реализована система классификации изображений на основе многослойного персептрона.

Полученные результаты подтвердили возможность применения feed-forward сетей для решения задач распознавания образов. Также было установлено, что такие сети уступают специализированным сверточным архитектурам при работе с изображениями, что является мотивацией для дальнейшего изучения CNN-моделей.
