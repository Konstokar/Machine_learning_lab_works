Практическая работа №2

Кластеризация данных с использованием алгоритма K-Means

1. Введение

Целью данной практической работы является изучение методов кластеризации данных и разработка программного приложения для группировки объектов на основе алгоритма k-means.

Кластеризация является одним из ключевых методов анализа данных и относится к задачам обучения без учителя. В отличие от задач классификации, при кластеризации отсутствуют заранее заданные метки классов, а алгоритм самостоятельно выявляет структуру данных.

В рамках работы была реализована система кластеризации с использованием библиотеки Scikit-learn языка программирования Python. В качестве исходных данных использовалась таблица признаков, содержащая информацию об объектах наблюдения.

Результатом работы программы является разделение объектов на группы (кластеры), а также возможность определения принадлежности нового объекта к одному из кластеров.

2. Формальная задача кластеризации. Цели и задачи кластеризации

Кластеризация представляет собой задачу разделения множества объектов на группы (кластеры) таким образом, чтобы объекты внутри одного кластера были максимально похожи друг на друга и максимально отличались от объектов других кластеров.

Формально задача кластеризации может быть описана следующим образом. Пусть имеется множество объектов:

X = \{x_1, x_2, ..., x_n\}

где каждый объект описывается набором признаков.

Требуется разделить множество объектов на k кластеров:

C = \{C_1, C_2, ..., C_k\}

таким образом, чтобы минимизировать внутрикластерное расстояние и максимизировать межкластерное расстояние.

Основные цели кластеризации:
	•	выявление структуры данных;
	•	сегментация объектов;
	•	уменьшение размерности данных;
	•	подготовка данных для дальнейшего анализа.

3. Обучение без учителя

Обучение без учителя (unsupervised learning) — это подход машинного обучения, при котором алгоритм обучается на данных без заранее известных правильных ответов.

В задачах обучения без учителя модель самостоятельно выявляет закономерности в данных.

К основным задачам обучения без учителя относятся:
	•	кластеризация;
	•	обнаружение аномалий;
	•	понижение размерности данных;
	•	извлечение скрытых структур.

Кластеризация является одной из наиболее распространённых задач данного типа.

4. Обнаружение аномалий и новизны в данных

Обнаружение аномалий представляет собой задачу выявления объектов, существенно отличающихся от основной массы данных.

Такие объекты могут быть:
	•	ошибками измерений;
	•	редкими событиями;
	•	мошенническими действиями;
	•	нестандартными объектами.

Методы кластеризации могут использоваться для обнаружения аномалий следующим образом:
	•	объекты, находящиеся далеко от центров кластеров, считаются аномальными;
	•	малочисленные кластеры могут интерпретироваться как необычные группы данных.

5. Метрики близости наблюдений

Для определения сходства объектов используются различные метрики расстояния.

Наиболее распространённые метрики:

Евклидово расстояние

d(x,y) = \sqrt{\sum (x_i - y_i)^2}

Наиболее часто используется в алгоритме k-means.

Манхэттенское расстояние

d(x,y) = \sum |x_i - y_i|

Косинусное расстояние

Используется для оценки угла между векторами признаков.

Выбор метрики зависит от природы данных и решаемой задачи.

6. Алгоритм k-means

Алгоритм k-means является одним из наиболее популярных методов кластеризации.

Основная идея алгоритма заключается в разбиении данных на k кластеров, каждый из которых характеризуется центром (центроидом).

Алгоритм выполняет следующие шаги:
	1.	Случайным образом выбираются k начальных центров кластеров.
	2.	Каждый объект относится к ближайшему центру.
	3.	Пересчитываются центры кластеров как среднее значение объектов внутри кластера.
	4.	Шаги 2–3 повторяются до сходимости алгоритма.

Цель алгоритма — минимизация внутрикластерной суммы квадратов расстояний:

J = \sum_{i=1}^{k} \sum_{x \in C_i} ||x - \mu_i||^2

где \mu_i — центр кластера.

7. Сети Кохонена и принципы их обучения

Сети Кохонена относятся к классу самоорганизующихся нейронных сетей.

Они предназначены для выполнения кластеризации и визуализации многомерных данных.

Основная идея сети заключается в том, что нейроны организуются в двумерную карту, где соседние нейроны представляют похожие объекты.

Процесс обучения включает:
	1.	выбор входного вектора;
	2.	определение нейрона-победителя;
	3.	корректировку весов нейрона и его соседей.

8. Самоорганизующиеся карты Кохонена

Самоорганизующиеся карты (Self-Organizing Maps, SOM) — это нейронные сети, которые позволяют отображать многомерные данные на двумерную карту.

Они широко применяются для:
	•	визуализации данных;
	•	кластеризации;
	•	анализа больших наборов данных.

Карты Кохонена позволяют выявлять скрытые структуры в данных.

9. Проблемы обучения сетей Кохонена

К основным проблемам обучения сетей Кохонена относятся:
	•	сложность выбора параметров обучения;
	•	зависимость результата от начальных весов;
	•	вычислительная сложность при работе с большими данными;
	•	трудности интерпретации результатов.

Несмотря на это, карты Кохонена остаются эффективным инструментом анализа данных.

10. Модель «нейронного газа»

Нейронный газ является модификацией алгоритмов кластеризации и самоорганизующихся сетей.

Основная идея заключается в адаптации весов нейронов в зависимости от расстояния до входного вектора.

В отличие от сетей Кохонена, нейронный газ не использует фиксированную топологию сети, что позволяет более гибко адаптироваться к структуре данных.

11. Метрики оценки качества кластеризации

Для оценки качества кластеризации используются различные метрики.

Silhouette Score

Показывает, насколько объект похож на свой кластер по сравнению с другими кластерами.

Значение варьируется от −1 до 1.

Davies–Bouldin Index

Оценивает компактность кластеров и расстояние между ними.

Чем меньше значение, тем лучше качество кластеризации.

Inertia

Внутрикластерная сумма квадратов расстояний.

Используется в алгоритме k-means для оценки качества модели.

12. Практическое применение кластеризации

Методы кластеризации широко применяются в различных областях:
	•	сегментация клиентов в маркетинге;
	•	анализ поведения пользователей;
	•	обработка изображений;
	•	анализ биологических данных;
	•	обнаружение мошенничества.

Кластеризация позволяет выявлять скрытые структуры данных и принимать решения на основе полученных групп объектов.

13. Описание реализованного приложения

В рамках практической работы было разработано приложение для кластеризации данных с использованием алгоритма k-means.

Программа реализована на языке Python с использованием библиотеки Scikit-learn.

В качестве входных данных используется таблица признаков в формате CSV, где строки представляют объекты наблюдения, а столбцы — признаки.

Алгоритм выполняет следующие действия:
	1.	загрузка данных из файла;
	2.	обучение модели кластеризации k-means;
	3.	определение центров кластеров;
	4.	сохранение обученной модели;
	5.	определение принадлежности нового объекта к кластеру.

Модель позволяет автоматически группировать объекты на основе их характеристик.
