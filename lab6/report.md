Практическая работа №6

Модели большого языкового моделирования (LLM)

1. Введение

Целью данной практической работы является изучение принципов работы моделей большого языкового моделирования (Large Language Models, LLM) и разработка простого приложения, использующего такие модели для генерации текстовых ответов.

В последние годы LLM стали одним из ключевых направлений развития искусственного интеллекта. Они способны обрабатывать и генерировать текст, вести диалог, отвечать на вопросы и выполнять широкий спектр задач, связанных с обработкой естественного языка.

В рамках работы было реализовано приложение, использующее локальную языковую модель семейства LLaMA, запущенную через Ollama.

2. Общий принцип работы LLM-моделей

LLM-модели представляют собой нейронные сети, обученные на больших объёмах текстовых данных. Основной задачей модели является предсказание следующего слова (токена) в последовательности.

Работа модели строится следующим образом:
	1.	входной текст разбивается на токены;
	2.	токены преобразуются в числовые представления (эмбеддинги);
	3.	модель обрабатывает последовательность с помощью архитектуры трансформера;
	4.	на выходе формируется вероятность следующего токена;
	5.	процесс повторяется до формирования полного ответа.

Таким образом, модель генерирует текст по одному токену, формируя осмысленный ответ.

3. Архитектура LLM

Современные LLM основаны на архитектуре Transformer, предложенной в 2017 году.

Основные компоненты:
	•	механизм внимания (Attention);
	•	многослойные нейронные сети;
	•	позиционное кодирование.

Механизм внимания позволяет модели учитывать контекст всей последовательности, а не только соседние элементы.

Это делает LLM значительно более эффективными по сравнению с классическими рекуррентными моделями.

4. Использование LLaMA через Ollama

В данной работе использовалась локальная модель LLaMA, доступ к которой осуществлялся через Ollama.

Ollama представляет собой инструмент, позволяющий запускать LLM локально на компьютере пользователя и взаимодействовать с ними через HTTP API.

Преимущества данного подхода:
	•	отсутствие необходимости в API-ключах;
	•	возможность работы без интернета;
	•	высокая скорость отклика;
	•	контроль над данными.

5. Описание реализованного приложения

В рамках работы было разработано консольное приложение, реализующее диалог с LLM.

Основной функционал
	•	ввод текста пользователем;
	•	отправка запроса в модель;
	•	получение ответа;
	•	вывод результата в консоль.

Архитектура приложения

Приложение состоит из двух основных компонентов:

5.1. Модуль взаимодействия с моделью

Отправляет HTTP-запрос к локальному серверу Ollama и получает ответ.

5.2. Пользовательский интерфейс (CLI)

Обеспечивает взаимодействие с пользователем через консоль.

Принцип работы приложения
	1.	пользователь вводит запрос;
	2.	запрос передаётся в LLM;
	3.	модель генерирует ответ;
	4.	результат выводится пользователю.

Особенности реализации
	•	используется HTTP API Ollama;
	•	применяется текстовый промпт с указанием роли модели;
	•	реализован цикл общения (чат);
	•	предусмотрен выход из программы.

6. Пример работы приложения

You: What is machine learning?
AI: Machine learning is a field of artificial intelligence...

Модель генерирует осмысленные и связные ответы, учитывая контекст запроса.

7. Практическое применение LLM

LLM находят применение в широком спектре задач:
	•	чат-боты и виртуальные ассистенты;
	•	генерация текстов;
	•	автоматизация поддержки пользователей;
	•	анализ и обработка документов;
	•	программирование и генерация кода.

8. Преимущества LLM
	•	способность работать с естественным языком;
	•	универсальность;
	•	высокая гибкость;
	•	возможность генерации новых текстов.

9. Ограничения LLM
	•	высокая вычислительная сложность;
	•	возможные ошибки и «галлюцинации»;
	•	зависимость от качества обучающих данных;
	•	большие требования к ресурсам.

Использование локальной модели позволило продемонстрировать практическую применимость LLM без использования внешних API.

Полученные результаты подтверждают, что LLM являются мощным инструментом обработки и генерации текста и имеют широкие перспективы применения.
