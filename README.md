Lab 5 — Generative Adversarial Networks (GAN)

Лабораторная работа посвящена изучению генеративно-состязательных нейронных сетей (GAN) и анализу современных систем, способных создавать новый контент: изображения, аудио и видео.

В отличие от предыдущих лабораторных работ, данная работа носит обзорно-практический характер и направлена на изучение уже существующих решений.

Цель работы
	•	изучить архитектуру GAN-моделей
	•	проанализировать современные генеративные системы
	•	протестировать инструменты генерации контента
	•	сравнить возможности различных подходов

Что такое GAN

Генеративно-состязательные сети состоят из двух моделей:
	•	Generator (генератор) — создаёт новые данные
	•	Discriminator (дискриминатор) — определяет, реальные данные или сгенерированные

Обучение происходит в виде «соревнования»:
	•	генератор пытается обмануть дискриминатор
	•	дискриминатор пытается распознать подделку

Принцип работы

Noise → Generator → Fake Data → Discriminator → Real / Fake

Со временем генератор начинает создавать всё более реалистичные данные.

Рассмотренные системы

Генерация изображений — Stable Diffusion
	•	генерация изображений по тексту
	•	высокая детализация
	•	поддержка различных стилей

Генерация аудио — Riffusion
	•	генерация музыки в реальном времени
	•	работа через спектрограммы

Генерация видео — Runway ML
	•	генерация видео по тексту
	•	редактирование сцен
	•	удаление объектов

Практическая часть

В рамках работы были протестированы генеративные модели:

Генерация изображений
	•	создание изображений по текстовым описаниям
	•	получение реалистичных и стилизованных результатов

Генерация аудио
	•	создание коротких музыкальных фрагментов
	•	генерация в реальном времени

Генерация видео
	•	создание коротких видеосцен
	•	применение AI-редактирования

Сравнение систем

Тип	Система	Особенности
Изображения	Stable Diffusion	высокое качество
Аудио	Riffusion	генерация музыки
Видео	Runway ML	генерация и редактирование

 Преимущества GAN
	•	генерация новых данных
	•	высокая реалистичность
	•	универсальность применения

Ограничения
	•	высокая вычислительная сложность
	•	нестабильность обучения
	•	возможные артефакты

Применение

GAN используются в:
	•	генерации изображений
	•	создании контента
	•	медицине
	•	игровой индустрии
	•	обработке изображений

Вывод

GAN-модели являются мощным инструментом генерации данных и активно применяются в современных AI-системах. Несмотря на сложность обучения, они демонстрируют впечатляющие результаты в создании реалистичного контента.
