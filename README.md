# Machine_learning_lab_works

Machine Learning Lab Works

Репозиторий содержит практические работы по дисциплине «Методы машинного обучения», выполненные в рамках магистратуры.

Проект охватывает ключевые направления машинного обучения:
	•	нейронные сети прямого распространения (MLP)
	•	кластеризация (K-Means)
	•	рекуррентные сети и ассоциативная память (Hopfield Network)


Структура репозитория

Machine_learning_lab_works/
│
├── lab1/   # Feed-Forward Neural Network (MLP)
├── lab2/   # K-Means Clustering
├── lab3/   # Hopfield Network (Associative Memory)


Лабораторная работа 1

Feed-Forward нейронные сети (MLP)

Цель

Реализация многослойного персептрона для классификации изображений.


спользуемые технологии
	•	Python
	•	TensorFlow / Keras
	•	NumPy


Структура

lab1/
│
├── dataset/              # изображения, разбитые по классам
├── model.py              # архитектура сети
├── utils.py              # загрузка данных
├── train.py              # обучение модели
├── predict.py            # распознавание изображения



Архитектура модели
	•	Flatten слой (преобразование изображения в вектор)
	•	Dense (256, ReLU)
	•	Dense (128, ReLU)
	•	Dense (Softmax)


Запуск

Обучение модели

python train.py

Предсказание

python predict.py



Функциональность
	•	обучение модели на изображениях
	•	оценка accuracy
	•	сохранение модели
	•	классификация новых изображений


Особенности
	•	используется MLP (без CNN)
	•	изображения нормализуются
	•	применяется sparse_categorical_crossentropy


Лабораторная работа 2

Кластеризация (K-Means)

Цель

Реализация алгоритма кластеризации для анализа табличных данных.


Используемые технологии
	•	Python
	•	Scikit-learn
	•	Pandas
	•	NumPy


Структура

lab2/
│
├── data/
│   └── dataset.csv       # таблица признаков
│
├── kmeans_model.py       # модель K-Means
├── utils.py              # загрузка данных
├── train.py              # обучение
├── predict.py            # определение кластера



Данные

Каждый объект описывается набором признаков:
	•	Age
	•	Income
	•	SpendingScore
	•	Visits
	•	Purchases


Алгоритм

Используется алгоритм:

K-Means (k = 3)



Запуск

Обучение

python train.py

Предсказание

python predict.py



Функциональность
	•	загрузка данных из CSV
	•	кластеризация объектов
	•	определение центров кластеров
	•	предсказание кластера для нового объекта


Интерпретация

Кластеры могут соответствовать, например:
	•	низкой активности клиентов
	•	средней активности
	•	высокой активности


Лабораторная работа 3

Рекуррентные сети (Ассоциативная память)

Цель

Реализация модели ассоциативной памяти для восстановления зашумлённых изображений.


Используемые технологии
	•	Python
	•	NumPy


Структура

lab3/
│
├── data/
│   └── patterns.py       # эталонные изображения
│
├── hopfield.py           # сеть Хопфилда
├── utils.py              # шум и визуализация
├── train.py              # обучение
├── predict.py            # восстановление образа



Модель

Используется:

Hopfield Network



Данные
	•	изображения размером 10×10
	•	бинарные значения (0 / 1)
	•	всего 12 образов (цифры + символы)


Принцип работы
	1.	сеть запоминает образы
	2.	на вход подаётся зашумлённое изображение
	3.	сеть сходится к ближайшему устойчивому состоянию
	4.	восстанавливается оригинальный образ


Запуск

python train.py
python predict.py


Функциональность
	•	обучение по правилу Хебба
	•	добавление шума к изображениям
	•	восстановление образов
	•	визуализация в консоли

Особенности
	•	рекуррентная архитектура
	•	ассоциативная память
	•	работа с бинарными изображениями
	•	устойчивость к шуму

Сравнение лабораторных работ

Лаба	Тип обучения	Модель	Задача
1	С учителем	MLP	Классификация
2	Без учителя	K-Means	Кластеризация
3	Без учителя	Hopfield	Восстановление образов
